# Streamlit-Projekte

Drei Übungsprojekte mit Python und Streamlit.

| Ordner | Inhalt |
|---|---|
| `todo_app` | To-Do-Liste mit Session State und Formular |
| `chinook_dashboard` | Dashboard mit SQLite, KPIs und Diagrammen |
| `ausgaben_tracker` | Ausgabenverwaltung mit Validierung, Tabelle und Diagramm |

## Starten

    pip install -r requirements.txt
    streamlit run app.py

Für die To-Do-App: `streamlit run todo_app.py`
